# Libertaria Publishing Cycle v1

**Status:** Locked  
**Principle:** Signal-to-noise first; doctrine-aligned synthesis; source-backed when external claims are made.

## 1) Editorial Lanes

### A. EOD Dispatch (High Noise -> Low Signal)
**Purpose:** Daily triage and compression, not full narrative.

**Output:** Short dispatch candidate note (or no-publish).

**Rules:**
- Max 3 candidate items.
- Noise sources (X, HN, Tech blogs) are lead indicators only.
- No item graduates without primary-source verification.
- If no verified signal, skip publish.

### B. Sunday Signal Edition (High Signal -> Low Noise)
**Purpose:** Weekly strategic synthesis for Libertaria audience.

**Output:** Sonntagsauge / Dossier-style piece.

**Rules:**
- One core thesis that survives red-team pressure.
- 2-5 hard citations minimum.
- Include Claims Audit block.
- Include explicit Libertaria implications (exit rights, protocol power, sovereignty stack).

### C. Event-Triggered Dossier (Tectonic Mode)
**Trigger:** 1 major rupture or >=2 simultaneous high-impact shifts.

**Output:** Shadow Architect dossier (bi-weekly cadence max unless rupture).

**Rules:**
- Publish only when vector shift is real (6-24 month impact horizon).
- Use split-screen analysis (official narrative vs mechanism vs Libertaria verdict).
- Mandatory red-team section: "What if we are wrong?"

## 2) Source Hierarchy

### Tier 1 (Truth Layer)
- Official records: legislation text, vote rolls, hearing transcripts, regulator notices.
- First-party incident/status reports.
- Primary financial/governance filings.
- First-party project repos/releases/specs.

### Tier 2 (Context Layer)
- Reuters, FT, established investigative outlets.
- Domain specialists/Substack with track record.

### Tier 3 (Noise/Discovery Layer)
- X/Twitter, Hacker News, TechCrunch, social chatter.

**Promotion Rule:** Tier 3 cannot appear as core evidence without Tier 1 or strong Tier 2 corroboration.

## 3) Weekly Operating Rhythm

### Daily (EOD Window)
1. Scan sources by lane (internal ecosystem + external).
2. Score each item: impact, evidence quality, relevance to Libertaria lens.
3. Keep top 0-3; discard rest.
4. Open verification tasks for candidates.

### Sunday (Deep Edition)
1. Select one dominant thesis.
2. Build causal chain (who benefits; what mechanism; what changes).
3. Attach citations + quantitative anchors.
4. Run red-team inversion.
5. Publish only if thesis still holds.

## 4) Mandatory Blocks by Format

### EOD Dispatch Block
- **Signal/Noise Verdict**
- **Why it matters to Libertaria (2-4 lines)**
- **Verification status** (verified / pending / rejected)

### Sunday Edition Block
- **Executive Summary + 3 Axioms**
- **Tectonic Shift**
- **Infrastructure/Power Rails**
- **Markets as Alarm**
- **Red Team**
- **Claims Audit**
- **Strategic Imperatives**

## 5) Claims Audit Standard

For each major claim:
- Claim statement
- Source URL(s)
- Date
- Quant anchor (vote count, balance-sheet figure, outage duration, etc.)
- Confidence (High/Medium/Low)

No audit = no heavy publish.

## 6) Libertaria Lens (Hard Filter)

Before publishing, each piece must answer:
1. Does this affect exit rights?
2. Does this alter protocol-level power?
3. Does this increase or reduce dependency risk?
4. What is the actionable sovereignty response?

If fewer than 2 questions are meaningfully answered, it is likely noise.

## 7) Voice Protocol

- Keep the Maiwald cadence: sharp, anti-fluff, mechanism-first.
- Bilingual friction is tactical, not decorative.
- German terms used for conceptual precision only.
- No performative certainty; show confidence level explicitly.

## 8) Publish Gates

A piece can publish only if all are true:
- Thesis is clear in one sentence.
- Source quality passes hierarchy rules.
- Claims audit complete.
- Red-team objection addressed.
- Libertaria action angle is concrete.

- **Bi-weekly / rupture:** Shadow Architect dossier.

**This is the default editorial operating system until explicitly changed.**
