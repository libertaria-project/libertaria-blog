## SPEC-027: Scoped Impl Resolution (SIR)

### What It Solves

Rust's orphan rule prohibits implementing foreign traits for foreign types. This forces developers into workarounds like newtype wrappers, extension traits, and combinatorial enum dispatch. SPEC-027 replaces prohibition with **resolution**.

Instead of blocking impl conflicts at definition time, Janus resolves them at the **call site** through a five-stage pipeline:

1. **Profile Filter** — Gate impls by compilation profile
2. **Capability Filter** — Gate impls by runtime capabilities
3. **Import Filter** — Visibility by module import scope
4. **Specificity Scoring** — Exact type > subtype > generic > blanket
5. **CID Deduplication** — Content-addressed impl identity

### Implementation Status

| Stage | Status |
|-------|--------|
| Import Filter | ✅ Implemented |
| Specificity Scoring | ✅ Implemented |
| Profile Filter | 🔴 Stub (Phase 3) |
| Capability Filter | 🔴 Stub (Phase 3) |
| CID Deduplication | ⚠️ Partial |

### Verdict: Conditional Ratification

The core mechanism (Stages 3-4) is implemented and sound. Stages 1-2 should be documented as Phase 3 work. This allows progress while reserving profile/capability filtering for future implementation.

## SPEC-029: Reference Capabilities

### What It Enables

Reference capabilities (`iso`, `val`, `ref`, `tag`) provide Rust-style ownership with algebraic effects. This is Janus's answer to memory safety without garbage collection:

- `iso` — Isolated (exclusive, mutable, move-only)
- `val` — Value (copyable, immutable)
- `ref` — Reference (borrowed, mutable or immutable)
- `tag` — Tagged (type-state tracking)

### Implementation Status

**Zero implementation found.**

The spec is well-designed but the compiler has no reference capability support:
- No keyword recognition in lexer
- No `RefCap` type in semantic analysis
- No send-safety predicates

### Verdict: Not Ready for Ratification

This should be scheduled as an implementation sprint after SPEC-027 Stages 1-2 are complete. Ratifying a spec with zero implementation would be premature.
